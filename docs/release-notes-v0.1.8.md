# Aurora TV v0.1.8

电视遥控也能操作新版播放器控制条。

## 变更

v0.1.7 的播放器控制条（音量 / 倍速 / 清晰度 / 横屏 / 返回）和分类排序，三端代码本来是同一套；

这一版补上了**电视遥控器的焦点操作**：

- 播放器里按方向键 ↑ / ↓ 在 9 个按钮间移动焦点：
  播放 / -10s / +10s / 下一集 / 静音 / 倍速 / 清晰度 / 横屏 / 退出；
- 回车执行当前按钮：倍速逐档切换、清晰度自动 → 多码率循环、横屏直接切换；
- 焦点按钮显示白色高亮，遥控器可完成手机上的全部播放器操作；
- Windows 端用鼠标点按同样可用，触屏笔记本也支持边缘滑动返回。

## 已确认

- 三个平台都从同一个提交构建，功能一致；
- 电视端遥控实测：↑ 选中「暂停」、↑ 到「1x」回车切到 1.25x、↑ 到「横屏」回车进入横屏、Esc 退出；
- 分类页、排序、内置片源、同步等在三端均可用。
