# Aurora TV v0.1.14

首页精简：只保留播放历史 + 近期高分。

## 调整

- **播放历史**：首页第一行，来自本机观看记录，最多 10 条，直接续播；
- **近期高分**：第二行，筛选评分 **≥ 7.5** 的影片，按更新时间倒序，最多 24 条；
- Hero 大图从近期高分里取前 3 部轮播，不再随机取分类内容；
- 首页**不再展示**动作片、喜剧片、短剧等其他分类行；
- 分类页、搜索、片库、同步记录保持不变。

## 说明

- 评分来自当前 CMS 站点；如果这个站点所有影片评分都是 0，近期高分行会为空，可以换有评分的站点；
- 播放历史只有实际播放过、且进度大于 5 秒的记录才会出现；
- 电视 / Windows 端同样生效。
