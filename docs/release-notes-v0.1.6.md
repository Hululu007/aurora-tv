# Aurora TV v0.1.6

分类页 + 手机边缘返回手势。

## 新增

- **分类页**：电影 / 电视剧 / 动漫 / 短剧 / AI短剧 / 综艺
  - 按当前站点自动映射分类（如「电影」会合并动作片、喜剧片、科幻片等）；
  - 手机 3 列、桌面自适应多列，支持「加载更多」分页；
  - 没有对应分类时显示明确提示，例如 AI短剧会提示换站点；
  - 底部导航和桌面顶栏都新增「分类」入口。
- **左右边缘滑动返回**：
  - 从屏幕左边缘向右滑，或右边缘向左滑；
  - 详情、搜索、设置、片库关闭；分类页返回首页；
  - 只识别屏幕边缘 28px 内起手、横向位移 ≥64px 的手势，不和竖向滚动冲突。
- 修复分类页在 320px 小屏的排版与底部导航适配。

## 其他

- 内置 5 个 CMS 片源、三端播放记录同步保持不变；
- 分类数据来自当前站点，切换片源后会重新加载；
- 手机端左右滑动返回不依赖系统导航栏，鸿蒙/安卓浏览器同样可用。
