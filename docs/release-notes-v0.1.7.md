# Aurora TV v0.1.7

手机播放器完整控制条 + 分类排序。

## 手机播放器

- **点按视频显隐控制条**，4 秒无操作自动隐藏，点一下秒回；
- **音量**：音量条 + 静音按钮；
- **倍速**：0.5x / 0.75x / 1x / 1.25x / 1.5x / 2x；
- **清晰度**：HLS 多码率源会自动列出 1080P / 720P 等，可选「自动」；单码率线路显示「清晰度」不可用；
- **横屏**：一键全屏 + 横屏，支持系统方向锁定时直接锁定；不支持时自动用画面旋转兜底；
- **返回**：顶部「返回」、底部「返回」和右上角关闭三个入口都能退出；
- 进度条支持拖动/点击跳转，保留 -10s / +10s / 下一集；
- 修复新选集错误继承上一集进度的问题（第一集续播只在从「继续观看」进入时生效）。

## 分类页

- 分类改为：电影 / 电视剧 / 动漫 / 短剧 / **动漫短剧** / 综艺；
- 新增排序：**默认 / 时间 / 评分 / 人气 / 热度**，对当前已加载内容重新排列；
- 排序按钮在分类标签下方，手机和桌面都可见。

## 说明

- 清晰度选项取决于片源是否提供多码率 master m3u8；很多短剧/直链只有单码率，此时按钮置灰。
- 安卓 WebView 的音量最终仍受系统媒体音量影响，音量条能调整播放器音量并静音。
- 横屏在部分系统 WebView 里不允许锁定方向，会退化为画面旋转，按提示横拿手机即可。
- 分类排序只对已加载的当前页/已加载更多内容排序，不会重新请求整个分类。
