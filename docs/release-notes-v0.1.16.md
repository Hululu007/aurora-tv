# Aurora TV v0.1.16

新增打赏通道。

## 新增

- 设置 → 关于 → **支持开发**：
  - 微信赞赏码 / 支付宝收款码切换；
  - 「支持一下」按钮，弹窗内扫码；
  - 明确写了「完全自愿，不影响任何功能」。
- README 增加「支持开发」区，放同一组二维码。
- 二维码已裁成纯码，去掉了原图里的姓名文字和平台营销边框；原始截图未提交到仓库。

## 说明

- 打赏不会解锁任何功能，也不会改变播放体验；
- 微信/支付宝扫码后金额自定；
- 二维码图片在 `public/donate/`，想换码直接替换同名文件即可。
