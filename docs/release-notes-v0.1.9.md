# Aurora TV v0.1.9

手机播放器手势补全。

## 手机播放器手势

- **点按视频**：显示/隐藏控制条；
- **横向滑动**：快进 / 后退，按滑动距离换算（最大 ±120 秒），实时显示目标时间；
- **左半屏上下滑**：调亮度（0.3x – 1.6x，画面滤镜）；
- **右半屏上下滑**：调音量，实时显示百分比；
- 手势进行中显示居中提示，松手后自动恢复控制条；
- 屏幕左右边缘 28px 内仍然留给「边缘返回」，不会误触快进。

## 已有手势

- 左/右边缘向内滑动：关闭详情、搜索、设置、片库，分类页回首页，播放器退出；
- 底部导航、海报墙、分类标签均可触摸滚动；
- 所有页面适配安全区 / 底部手势条。

## 已验证

- 390px 安卓 UA：横向滑动把进度从 0:03 拖到 0:38，提示「快进 0:35 · 0:38」；
- 左半屏上滑亮度从 100% 到 153%，视频滤镜同步；
- 右半屏上下滑调节音量，提示百分比；
- 电视遥控、Windows 全屏/铺满、分类排序保持 v0.1.8 行为不变。
