# Aurora TV v0.1.2

手机端适配的修正版本。

## 修复

- **Android TV 初始焦点回归**：v0.1.1 用 `hover: none` 判断触屏，电视没有鼠标也会命中，导致首页 / 详情打开后没有默认选中项。现改为按 **720px 宽度**判断，手机保持无焦点环，电视恢复自动聚焦第一个按钮。
- 手机横屏（宽度 > 720）也按桌面标准处理，不再误关焦点。

## 手机端功能（同 v0.1.1）

- 底部四栏导航、刘海 / 手势条安全区
- 悬浮海报 Hero、矮屏自适应
- 详情 4 列选集、粘性返回
- 搜索 3 列、隐藏电视键盘
- 设置 / 片源纵向表单
- 播放器竖屏横屏提示、控件重排
- 触屏不抢焦点、输入框 16px 防缩放、弹层锁定背景滚动

## 包含文件

| 平台 | 文件 |
| --- | --- |
| Windows | `AuroraTV_0.1.2_x64-setup.exe` / `.msi` |
| Android / TV 64 位 | `AuroraTV_0.1.2_arm64-v8a.apk` |
| Android / TV 32 位 | `AuroraTV_0.1.2_armeabi-v7a.apk` |

签名与 v0.1.0 / v0.1.1 一致，可直接覆盖安装。

## 已知限制

- **type 3 spider 站点（jar / drpy）仍不支持**，当前使用 type 1 CMS 站点；已支持 `parses` 解析线路。
- 播放器暂不支持直播（`lives`）与弹幕。
- 手机横屏的首页仍使用宽屏排版（播放器已适配横屏）。
